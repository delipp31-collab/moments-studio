MOMENTS STUDIO — GITHUB PAGES EDITION

PUBLISH THE CREATOR
1. Create a Public GitHub repository named moments-studio.
2. Upload index.html to the repository root and commit.
3. Open Settings > Pages.
4. Choose Deploy from a branch, branch main, folder /(root), then Save.
5. Your URL will be https://YOUR-USERNAME.github.io/moments-studio/

FEATURES
- Nine occasion templates: Birthday, Anniversary, Best Friend, Love & Romance, Thank You, Congratulations, Wedding, Get Well Soon, Just Because.
- Personalization, themes, live preview, share-link generation.
- Photo selection and standalone HTML gift export.

PHOTO / SHARING NOTES
Share links encode the greeting text and public photo URL. A photo selected from the phone is not included in a share link. Use a public direct image URL for link-based sharing, or use Export gift HTML to embed the selected photo in a standalone file.

GITHUB PAGES LIMITATIONS
GitHub Pages is static hosting. This project has no server-side accounts, database, permanent photo upload, private admin panel, payment processing, or automatic server-side page creation. Exported gift HTML files can be uploaded to the same repository and shared by their own GitHub Pages URL.

This is an independent greeting creator inspired by the general idea of digital gift experiences. It is not affiliated with OurMoments and does not copy its source code, branding, paid templates, or proprietary assets.
