MOMENTS STUDIO V2 — GITHUB PAGES

This update replaces the basic one-screen creator with a multi-step gift builder inspired by the general experience of interactive digital gifts.

PUBLISH THE UPDATE
1. Extract this ZIP.
2. Open your GitHub repository: delipp31-collab/moments-studio.
3. Choose Add file > Upload files.
4. Upload the new index.html, replacing the old index.html.
5. Commit changes. Keep Pages set to branch main and folder /(root).
6. Wait for deployment and refresh https://delipp31-collab.github.io/moments-studio/

INCLUDED
- 9 occasions
- 5-step creator: recipient/sender details, cake/style, balloon messages, up to 5 photos with captions, personal letter
- Recipient sequence: gift/ribbon reveal, greeting, wish/cake interaction, balloon messages, photo memories, letter reveal
- Shareable link generated from the gift data

LIMITS
GitHub Pages is static hosting. This build does not include accounts, a database, permanent photo storage, payment processing, private admin tools or automatic server-side gift page creation. Share links encode gift data in the URL; embedded photos can make links very long and exceed browser URL limits. For dependable photo sharing, a backend/storage service is required.

Independent implementation with original code and design; not affiliated with OurMoments and does not copy its source code, logo or proprietary media.
